# E-Commerce-Sales-Performance-Analysis-Power-BI
Power BI-based e-commerce sales analysis and interactive dashboard project to track KPIs, analyse revenue trends, evaluate product and geographical performance, and monitor order cancellations.
📌 Project Overview

Developed an interactive Power BI dashboard to analyse 15,690 e-commerce orders and generate actionable business insights into sales performance, revenue trends, product performance, geographical sales, and order cancellations.

🎯 Project Objectives

Monitor key sales and revenue performance indicators.

Identify monthly revenue trends and top-performing products and cities.

Analyse delivery status and revenue lost due to cancellations.

Explore geographical sales distribution across states.

Enable interactive data exploration using slicers and visualisations.

🛠️ Tools & Technologies

Microsoft Power BI – Dashboard development and visualisation

Power Query – Data cleaning and transformation

DAX – Measures and KPI calculations

Google Drive – Cloud-based data source

📊 Key Features

KPI cards for Total Orders, Total Revenue, Total Sales, Average Order Value (AOV), and Revenue Lost to Cancellations.

Monthly revenue trend analysis.

City-wise and product-wise revenue comparisons.

Delivery-status analysis.

State-level geographical sales mapping.

Interactive Purchase Date and Category slicers.

Monthly date-coverage validation to identify partial-month data.

💡 Business Value

The dashboard provides an interactive overview of e-commerce performance, helping users identify revenue trends, understand geographical and product-level performance, and evaluate cancellation-related revenue loss.

📚 Key Learnings

Data extraction, cleaning, and transformation.

Data modelling and relationship management.

DAX measure development for business KPIs.

Interactive dashboard design and data visualisation.

Data validation and accurate interpretation of analytical results.

👨‍💻 Project Summary

This project demonstrates an end-to-end data analytics workflow, from data extraction and transformation to data modelling, KPI development, and interactive dashboard reporting.
